# 阿尔图 Mod v0.3.1 修复报告

日期：2026-10-10。基于 v0.3.0，未改动未定稿设计、卡牌 ID 或存档结构。

## 改动

1. 女术士的牌盒／宝盒：开场选牌提示改为“选择一张苏丹牌加入手牌。”。通用选择界面不再错误使用原版“变化”提示，实际换牌逻辑保持原状。
2. 伤害显示：四阶杀戮苏丹牌加入原生 DamageVar，伤害文本使用 `{Damage:diff()}`；调兵遣将的伤害与格挡文本同样接入原生预览。原代码的伤害调用已有 `ValueProp.Move`，本机原版易伤按此属性结算；未额外乘一次易伤倍率，也未改变诅咒／技能身份。银、金杀戮仍无视格挡。
3. 四阶奢靡牌均改为自身目标，直接打出，不再要求玩家指定敌人。青铜奢靡自动使用的子牌与顺应皇命自动使用的苏丹牌，按子牌自己的目标类型决定是否选择敌人。

## 本机验证

- 游戏 v0.111.0；BaseLib v3.4.7；.NET SDK 9.0.318。
- Release 编译：0 错误、0 警告。
- 隔离的游戏实例只加载 BaseLib 和阿尔图，关闭 Steam 初始化，使用独立的 `ArtuModFix031Verification` 数据目录；未使用玩家存档。
- 原有回归加新增检查合计 **241 项通过，0 项失败**。结果保存在 `verification/v031-smoke/runtime.json`。
- 新检查包括选牌文本、四张奢靡的目标和诅咒身份、四阶杀戮的易伤预览与实际伤害一致、银／金无视格挡，以及调兵遣将保持技能身份并正常结算易伤。
- 对单个普通易伤目标，岩石／青铜／白银／黄金杀戮分别造成 16／27／52／99 伤害；调兵遣将造成 9 伤害。伤害使用原生取整。
- 玩家这局日志显示缩小甲虫执行 SHRINKER_MOVE 后，才再次使用岩石杀戮与调兵遣将。原版“缩小”减伤30%，与易伤乘算为 `0.7×1.5=1.05`，11和6取整后仍为11和6。新增相同状态组合的原生游戏命令检查，两张牌的预览与实际伤害均符合该结果。日志没有逐次扣血数值，不能据此重建整场战斗所有伤害；但后一回合的表象可按该原生规则复现。没有删除缩小减益，也没有为苏丹牌另加易伤乘数。
- 无界面测试提前退出会产生引擎资源释放警告，保留日志，不等于完整图形界面或联机验收。其他已启用模组的干扰尚未逐个验证。
